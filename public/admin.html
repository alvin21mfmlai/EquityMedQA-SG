In the CSV files, text that begins with =, +, - or @ gets a leading apostrophe, so that a spreadsheet shows it as text and does not run it as a formula. The JSON files carry the text exactly as typed.

Add a clinician

Every doctor can review all 250 questions and write new ones; nothing needs assigning. Phase 1A references are assigned with node scripts/admin.mjs assign-refs --annotators 2,3 --base-ids ids.txt, and rating sets (v1) with node scripts/admin.mjs assign --annotators 2,3 (see README). A test account is for trying the site, for example by a supervisor: it gets three demo references, so its login shows all three tasks, and what it enters is left out of the exports unless you ask for it.
